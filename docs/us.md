# Parcours Utilisateur

## Gestion du site

### Export des données

Un bénévole de la commission jeu doit pouvoir en selectionnant une option dans le menu télécharger un fichier contenant la majorité des données sur les jeux. Ce fichier devra être lisible par un logiciel de tableur (Google sheet).

Voici les données qui ne seront pas récupérables :

- Le QRcode

## Inventaire

### Récupération des données via Google sheet

Le gestionnaire du logiciel doit pouvoir importer les données existantes.

### Ajout d’un jeu

La commission jeu doit pouvoir ajouter un jeu en étant guidé pour bien rentrer toutes les informations  principales du jeu.

Les informations principales du jeu sont :

- Son nom
- Son numéro qui doit être unique. Le logiciel devra proposer un nombre par défaut
- Le prix du jeu
- Le type de jeu (jeu de société, jeu en bois, jeu de rôle, jouet)
- L’origine du jeu (achat, don et source du don, etc)
- Année d’obtention du jeu par la Licorne
- Année de sortie du jeu afin de suivre l’édition
- Des commentaires liés aux jeux
- Est-ce que le jeu est catégorisé pour les enfants ou les adultes
- Le lien vers la page MyLudo du jeu afin de récupérer plus tard d’autres informations de manière automatique et de s’assurer que l’on récupère les informations du bon jeu

Une fois les informations validées, les traitements suivants seront effectués : 

- le logiciel devra créer le QRcode correspondant au jeu et qui ccontiendra le lien vers la page du jeu dans le logiciel
- le logiciel devra essayer de récupérer les informations secondaires à partir de celles déjà fournies

### Localisation du jeu

Un bénévole doit pouvoir facilement savoir où un jeu se trouve et modifier sa localisation.

### Modification de données par lots

Un bénévole doit pouvoir selectionner facilement un ensemble de jeux et modifier en masse certaines caratéristiques de ces jeux.

### Édition des étiquettes des jeux

La commission jeu doit pouvoir éditer et imprimer des planches d’étiquettes d’un ensemble de jeux pour pouvoir les coller par la suite sur ceux-ci.
